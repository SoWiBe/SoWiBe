## Алексей Грызлов

Backend-разработчик на .NET. Пишу REST API и сервисы на C#, интересуюсь внутренним устройством CLR, многопоточностью и проектированием систем.

Сейчас копаю в сторону производительности .NET: как работает сборщик мусора, чем `Span<T>` отличается от массива и почему `async/await` — это конечный автомат, а не поток.

### Проекты

**[tracking-service](https://github.com/SoWiBe/tracking-service)** — сервис учёта времени на .NET 8. Чистая архитектура, Minimal API с собственной абстракцией `IEndpoint` вместо контроллеров, EF Core и PostgreSQL. Пишу с прицелом на то, чтобы каждое архитектурное решение можно было объяснить и защитить.

**[AnemiaScan](https://github.com/SoWiBe/AnemiaScanApi)** — API и ML-модель для скрининга анемии. Связка бэкенда на .NET с обученной моделью.

**[HabitTrackerApp](https://github.com/SoWiBe/HabitTrackerApp)** — трекер привычек с бэкендом на ASP.NET Core и MongoDB. Первый заход в подход «один класс — один эндпоинт».
